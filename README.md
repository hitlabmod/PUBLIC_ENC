<h3 align="center">🦅 <span style="color:#9B59B6">Panduan Khusus Pterodactyl Panel</span></h3>
<!--╚═════════════════════════════════════════════════════════════════════════════════════════════════════════════════╝-->

<details>
<summary>📋 <b>Tutorial Lengkap Pterodactyl</b> (Klik untuk melihat)</summary>
<div style="border-left: 4px solid #9B59B6; padding-left: 15px; margin: 10px 0;">

### 📹 Video Tutorial
<a href="https://www.youtube.com/shorts/_3orqxFqo5A" target="_blank">
  <img src="https://img.youtube.com/vi/_3orqxFqo5A/maxresdefault.jpg" alt="Tutorial Pterodactyl Panel" style="max-width:100%; height:auto; border-radius:8px;">
</a>
<p align="center"><i>Klik gambar untuk menonton video tutorial</i></p>

### 📌 Prasyarat
- Akses ke Pterodactyl Panel
- Server dengan Egg Node.js
- File bot yang sudah siap diupload

### 🔧 Langkah-langkah Lengkap

1. **Login ke Panel Pterodactyl**
   - Masuk ke akun Anda di panel Pterodactyl
   - Pilih server yang ingin Anda gunakan

2. **Upload File Bot**
   - Klik tab "File Manager"
   - Gunakan tombol "Upload" untuk mengunggah semua file bot Anda
   - Alternatif: Gunakan SFTP untuk transfer file lebih cepat

3. **Konfigurasi Environment**
   - Klik tab "Startup"
   - Tambahkan variabel lingkungan yang diperlukan:
     - `BOT_TOKEN`: Token WhatsApp/Discord bot Anda
     - `PREFIX`: Prefix command bot (jika ada)
     - `NODE_VERSION`: Setel ke `16` atau `18`

4. **Perbarui package.json**
   - Pastikan package.json memiliki script start:

```json
{
  "name": "wilykun-bot",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  }
}
```

5. **Instal Dependensi**
   - Buka tab "Console"
   - Jalankan perintah:

```bash
npm install
```

6. **Jalankan Bot**
   - Setelah instalasi selesai, klik tombol "Start" di panel
   - Atau gunakan perintah di konsol:

```bash
npm start
```

7. **Pantau Log**
   - Lihat output konsol untuk memastikan bot berjalan
   - Periksa pesan error jika bot gagal memulai

### 🔄 Restart & Manajemen

- **Restart Otomatis**: Aktifkan opsi "Auto-restart on crash" di tab Startup
- **Jadwal Restart**: Konfigurasikan di bagian "Schedules" untuk restart rutin
- **Backup Data**: Gunakan fitur "Backups" untuk membuat cadangan reguler

### 💡 Tips Tambahan

- **Egg Kustom**: Jika perlu, administrator dapat membuat egg khusus untuk bot WhatsApp
- **Alokasi Sumber Daya**: Pastikan server memiliki RAM minimal 1GB untuk performa optimal
- **Optimalkan Startup**: Gunakan PM2 untuk manajemen proses yang lebih baik:

```bash
# Install PM2 globally
npm install -g pm2

# Start bot with PM2
pm2 start index.js --name wilykun-bot
```

- **Variabel di .env**: Jika menggunakan file .env, pastikan semuanya terkonfigurasi dengan benar:

```
# Contoh isi file .env
BOT_TOKEN=your_token_here
PREFIX=!
DISABLE_STORE=true
```

<h3 align="center">🚀 <span style="color:#8E44AD">Cara Menjalankan Bot di VPS</span></h3>
<!--╚═════════════════════════════════════════════════════════════════════════════════════════════════════════════════╝-->

<details>
<summary>📋 <b>Tutorial Lengkap VPS</b> (Klik untuk melihat)</summary>
<div style="border-left: 4px solid #8E44AD; padding-left: 15px; margin: 10px 0;">

### 📌 Prasyarat
- VPS dengan OS Ubuntu/Debian
- Minimal RAM: 1GB
- Hak akses root atau sudo

### 🔧 Langkah Instalasi

```bash
# Update paket sistem
sudo apt update && sudo apt upgrade -y

# Instal Node.js & npm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Instal PM2 (untuk menjalankan bot 24/7)
sudo npm install -g pm2

# Clone repositori bot
git clone https://github.com/username/wilykun-bot.git
cd wilykun-bot

# Instal dependensi
npm install

# Jalankan bot dengan PM2
pm2 start index.js --name wilykun-bot
pm2 save
pm2 startup
```

### 🔄 Perintah Berguna
- Restart bot: `pm2 restart wilykun-bot`
- Lihat log: `pm2 logs wilykun-bot`
- Monitor bot: `pm2 monit`

</div>
</details>

<h3 align="center">💻 <span style="color:#2ECC71">Cara Menjalankan Bot di RDP</span></h3>
<!--╚═════════════════════════════════════════════════════════════════════════════════════════════════════════════════╝-->

<details>
<summary>📋 <b>Tutorial Lengkap RDP</b> (Klik untuk melihat)</summary>
<div style="border-left: 4px solid #2ECC71; padding-left: 15px; margin: 10px 0;">

### 📌 Prasyarat
- Windows RDP dengan akses administrator
- Node.js versi 16 atau lebih tinggi

### 🔧 Langkah Instalasi

1. **Download dan instal Node.js** dari [nodejs.org](https://nodejs.org/)
2. **Download repositori bot** melalui GitHub atau transfer file
3. **Buka Command Prompt sebagai Administrator**

```batch
:: Arahkan ke folder bot
cd path\to\wilykun-bot

:: Instal dependensi
npm install

:: Instal pm2 untuk menjalankan bot di latar belakang
npm install -g pm2

:: Jalankan bot dengan PM2
pm2 start index.js --name wilykun-bot
```

4. **Buat file startup batch** bernama `start-bot.bat`:

```batch
@echo off
cd path\to\wilykun-bot
pm2 start index.js --name wilykun-bot
```

5. **Tambahkan ke startup Windows** dengan menekan `Win+R`, ketik `shell:startup`, dan salin shortcut `start-bot.bat`

</div>
</details>

<h3 align="center">📱 <span style="color:#F1C40F">Cara Menjalankan Bot di Termux</span></h3>
<!--╚═════════════════════════════════════════════════════════════════════════════════════════════════════════════════╝-->

<details>
<summary>📋 <b>Tutorial Lengkap Termux</b> (Klik untuk melihat)</summary>
<div style="border-left: 4px solid #F1C40F; padding-left: 15px; margin: 10px 0;">

### 📌 Prasyarat
- Aplikasi Termux terbaru
- Ruang penyimpanan yang cukup (min. 500MB)

### 🔧 Langkah Instalasi

```bash
# Update repositori Termux
pkg update && pkg upgrade -y

# Instal paket yang diperlukan
pkg install nodejs git ffmpeg imagemagick -y

# Clone repositori bot
git clone https://github.com/username/wilykun-bot.git
cd wilykun-bot

# Instal dependensi
npm install

# Jalankan bot
node index.js
```

### 💡 Tips untuk Termux
- Jalankan bot di latar belakang:
```bash
nohup node index.js > output.log 2>&1 &
```

- Detach dari sesi Termux tanpa mematikan bot:
```bash
# Tekan tombol
CTRL + D
```

- Simpan skrip starter (`start-bot.sh`):
```bash
#!/data/data/com.termux/files/usr/bin/bash
cd ~/wilykun-bot
node index.js
```

- Buat skrip dapat dieksekusi:
```bash
chmod +x start-bot.sh
```

<h3 align="center">☁️ <span style="color:#3498DB">Cara Menjalankan Bot di Replit</span></h3>
<!--╚═════════════════════════════════════════════════════════════════════════════════════════════════════════════════╝-->

<details>
<summary>📋 <b>Tutorial Lengkap Replit</b> (Klik untuk melihat)</summary>
<div style="border-left: 4px solid #3498DB; padding-left: 15px; margin: 10px 0;">

### 📌 Prasyarat
- Akun Replit (gratis atau berbayar)
- File bot yang sudah dikonfigurasi

### 🔧 Langkah-langkah Setup

1. **Buat Repl baru** dengan template Node.js
2. **Upload file-file bot** ke Replit
3. **Konfigurasikan Secrets** untuk variabel lingkungan:
   - Klik tombol "Tools" di sidebar
   - Pilih "Secrets"
   - Tambahkan kunci seperti `TOKEN_BOT`, `API_KEY`, dll.

4. **Konfigurasi package.json**:
```json
{
  "name": "wilykun-bot",
  "version": "1.0.0",
  "description": "WhatsApp Bot",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "@adiwajshing/baileys": "^4.4.0",
    "other-dependencies": "^1.0.0"
  }
}
```

5. **Konfigurasikan Run Button**:
   - Klik "⚙️" (settings)
   - Set "Run command" ke `npm start`

6. **Aktifkan Always On** (Fitur berbayar Replit):
   - Masuk ke tab "Deployment"
   - Konfigurasi untuk selalu aktif

### 💡 Tips Replit
- Gunakan `Uptimerobot` untuk ping Replit setiap 5 menit agar tetap aktif (untuk pengguna free)
- Simpan file sesi di folder persisten seperti `.data/`
- Tambahkan express server sederhana agar Replit tidak sleep:

```javascript
// Tambahkan di index.js
const express = require('express');
const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Bot is running!');
});

app.listen(port, () => {
  console.log(`Server berjalan di port ${port}`);
});
```
